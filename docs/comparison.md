# 电机类型对比

本章从控制复杂度、反馈需求、效率、精度和适用场景比较 TT 电机、直流减速电机、步进电机和无刷电机。

## 本章目标

- 从控制复杂度、成本、效率和定位能力比较常见电机。
- 帮助读者根据应用场景选择合适的电机类型。
- 总结不同控制方法的主要取舍。

## 前置知识

建议先阅读 [电机控制总览](overview.md)，并根据需要查阅 [术语表](glossary.md)。

## 关键词汇与注释

| 中文术语 | English | 注释 |
| --- | --- | --- |
| 控制复杂度 | Control Complexity | 实现稳定可用控制所需的算法、传感器和调参难度。 |
| 功率密度 | Power Density | 单位体积或重量可输出的功率。 |
| 定位精度 | Positioning Accuracy | 实际位置接近目标位置的程度。 |
| 转矩脉动 | Torque Ripple | 输出转矩随时间或角度周期性波动。 |

## 总体对比

| 类型 | 控制入口 | 反馈需求 | 控制难度 | 典型优点 | 典型限制 |
| --- | --- | --- | --- | --- | --- |
| TT 电机 | PWM、电压方向 | 可选编码器 | 低 | 便宜、易用 | 精度低、寿命和一致性一般 |
| 直流减速电机 | PWM、电流、速度 | 编码器常见 | 中 | 转矩大、闭环成熟 | 齿隙、磨损、效率损失 |
| 步进电机 | 脉冲、方向、相电流 | 开环常见 | 中 | 定位简单、低速转矩大 | 失步、发热、高速弱 |
| 无刷电机 | 三相电压/电流 | 位置估计或传感器 | 高 | 高效率、高速、寿命长 | 驱动和控制复杂 |

## 控制方法比较

TT 电机和直流减速电机本质上多属于有刷直流电机控制。最简单方式是 PWM 开环调速，进一步可加入速度 PI 和位置环。它们的控制难点主要来自负载变化、摩擦、齿隙和电机参数离散。

步进电机的优势在于控制接口直接表达位置增量。只要负载在转矩能力内，开环也能完成定位。它的主要风险是没有反馈时无法确认实际位置，且高速区转矩快速下降。

BLDC 的控制难点在换相和电流矢量。六步换相能完成基本运行，FOC 能获得更低噪声、更低转矩脉动和更高效率，但需要电流采样、转子角度和更复杂计算。

## 选型建议

| 场景 | 推荐 |
| --- | --- |
| 教育小车、低成本移动平台 | TT 电机或带编码器 TT 电机 |
| 夹爪、升降、低速大转矩机构 | 直流减速电机 |
| 3D 打印机、CNC 小滑台、定量进给 | 步进电机 |
| 风扇、水泵、无人机、电动工具 | BLDC |
| 高效率、长寿命、高速运行 | BLDC |
| 低成本开环定位 | 步进电机 |

## 关键取舍

- 成本最低通常是 TT 电机，但控制精度和寿命有限。
- 开环定位最方便通常是步进电机，但必须留足转矩裕量。
- 高效率和高功率密度通常选择 BLDC，但控制和硬件成本更高。
- 需要输出轴真实位置时，编码器应尽量安装在输出轴侧，而不是只装在电机轴侧。

## 常见问题与误区

- “能转”不等于“可控”，控制性能必须结合反馈、负载和带宽判断。
- 只比较额定转矩不够，还要看速度范围、散热、峰值电流和工作制。
- 同一个电机加不同驱动器，控制性能可能差异很大。

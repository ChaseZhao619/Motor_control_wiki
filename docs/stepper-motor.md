# 步进电机控制

步进电机（Stepper Motor）把电脉冲转换为离散角位移。它常用于开环位置控制，但“给了多少步”并不等于“实际走了多少步”，因为负载过大、加速过快或共振都可能导致失步（Lost Step）。

## 本章目标

- 理解步进电机为什么能用脉冲表达位置增量。
- 解释整步、半步和细分控制的差异。
- 从二阶系统角度理解失步、共振和加减速曲线。

## 适合读者

适合关注 3D 打印机、CNC 小平台、滑台、定量进给和低成本开环定位的读者。

## 基本结构与工作原理

常见两相混合式步进电机（Two-phase Hybrid Stepper Motor）具有带齿转子和两相定子绕组。控制器按顺序给 A、B 两相通电，使合成磁场旋转，转子趋向对齐磁场方向。

基本步距角（Step Angle）常见为 `1.8°`，即每转 200 步。细分驱动（Microstepping）通过近似正弦电流让磁场更平滑地旋转。

## 关键词汇与注释

| 中文术语 | English | 注释 |
| --- | --- | --- |
| 步距角 | Step Angle | 单个整步对应的机械角度。 |
| 细分 | Microstepping | 通过控制相电流比例，把一个整步分成更小的指令位置。 |
| 保持转矩 | Holding Torque | 静止通电时抵抗外力转动的最大转矩。 |
| 拉出转矩 | Pull-out Torque | 给定速度下不失步可承受的最大负载转矩。 |
| 加减速曲线 | Acceleration Profile | 限制速度变化率，避免转矩不足和失步。 |

## 数学模型与变量定义

理想两相步进电机相电流为：

```math
i_A=I\cos\theta_e
```

```math
i_B=I\sin\theta_e
```

其中 `θ_e` 是电角度（Electrical Angle），`I` 是相电流幅值。合成磁场方向由 `θ_e` 决定。

### 参数说明

| 参数 | English | 含义 | 常见单位 | 说明 |
| --- | --- | --- | --- | --- |
| `i_A` | Phase A Current | A 相电流 | A | 流过 A 相绕组的电流。 |
| `i_B` | Phase B Current | B 相电流 | A | 流过 B 相绕组的电流。 |
| `I` | Current Amplitude | 相电流幅值 | A | 两相电流合成磁场的幅值，决定可产生的最大静态转矩。 |
| `θ_e` | Electrical Angle | 电角度 | rad 或 deg | 控制器希望定子磁场指向的电角度。 |
| `θ_r` | Rotor Electrical Angle | 转子电角度 | rad 或 deg | 转子实际磁场方向对应的电角度。 |
| `δ` | Load Angle | 负载角 | rad 或 deg | 定子磁场与转子之间的角度差。`δ` 过大时会失步。 |
| `K_s` | Stiffness Constant | 等效刚度常数 | N·m/A | 描述相电流产生磁拉力的能力。 |
| `M` | Microstep Count | 细分数 | 1 | 一个整步被分成的细分数量。 |
| `k` | Microstep Index | 细分索引 | 1 | 当前细分位置编号。 |

若转子实际电角度为 `θ_r`，简化电磁转矩可写为：

```math
\tau_e=K_s I\sin(\theta_e-\theta_r)
```

`K_s` 是等效刚度常数。令负载转矩为 `τ_L`，转动方程为：

```math
J\frac{d^2\theta_r}{dt^2}+B\frac{d\theta_r}{dt}+\tau_L
=K_s I\sin(\theta_e-\theta_r)
```

当角度误差 `δ=θ_e-θ_r` 较小时，`sinδ≈δ`：

```math
J\ddot{\theta}_r+B\dot{\theta}_r+K_sI\theta_r
=K_sI\theta_e-\tau_L
```

这表明步进电机开环系统像一个被磁场牵引的二阶弹簧-阻尼系统。加速过快时，转子跟不上旋转磁场，`δ` 过大后就会失步。

## 常见控制目标

- 开环位置控制：按目标步数输出脉冲。
- 平滑运动控制：通过细分和加减速曲线降低振动。
- 闭环步进控制：加入编码器，检测失步并修正。

## 主流控制方法

整步控制（Full-step Control）每次切换到下一个稳定磁场方向，转矩较大但振动明显。半步控制（Half-step Control）在单相和双相通电之间切换，分辨率提高一倍。细分控制让两相电流近似正弦变化：

```math
i_A=I_{max}\cos\left(\frac{k}{M}\frac{\pi}{2}\right)
```

```math
i_B=I_{max}\sin\left(\frac{k}{M}\frac{\pi}{2}\right)
```

`M` 为每整步细分数，`k` 为细分索引。细分提高平滑性，但不等于线性提高绝对定位精度，因为齿槽转矩、负载和电流误差仍会影响实际角度。

## 必要硬件背景

步进电机通常使用恒流斩波驱动器（Chopper Current Driver）。斩波驱动（Chopper Drive）指驱动器用开关方式快速调节绕组电压，使相电流围绕目标值上下波动。驱动器用较高母线电压加快绕组电流上升，再通过电流采样和开关斩波限制相电流。这样可以改善高速性能，因为绕组电感会阻碍电流快速变化。

## 优缺点与适用场景

优点是开环定位简单、低速转矩大、控制接口标准化。缺点是高速转矩下降、效率较低、发热明显、可能失步。适合 3D 打印机、CNC 小型平台、仪器滑台和低成本定位机构。

## 常见问题与误区

- 细分越高不等于实际精度越高；它主要改善平滑性和振动。
- 步进电机静止也会耗电发热，因为保持转矩需要相电流。
- 开环系统不能感知堵转或撞限位，关键机构应加入限位或编码器。
